# Projects
Personal projects of mine, cpanic is my most active one at the moment.

## cpanic.py
_cpanic_ is an offensive security penetration testing tool, with emphasis on passive reconnaissance. Some API keys will be needed to access some functionality for services like Shodan and Hunter. 

The tool is meant to be used in conjunction with a custom Debian-based Linux OS that I am developing called "HacknetOS", inspired by the game Hacknet. 

## get-formAdminIDOR.py
_get-formAdminIDOR.py_ is a python script that was quickly tacked together for the "Guided Pentest: Web" room on TryHackMe.

## ipecho.py
Simple python script that requests the ipecho[.]io website and parses the JSON that's returned.

## nameTBD.py
_nameTBD_ is a penetration testing tool meant for passive subdomain enumeration and reconnaissance by utilizing services like DNSdumpster and ICANN. Some remnants of what is now cpanic remain.

## wpa2stalker.py
This script is (at some point) meant to create a monitor-mode interface and listen for WPA2 traffic and decrypt it using a supplied key, though my wireless security knowledge is lacking and completion of this project is halted until I learn more about WPA2 and wireless security.
